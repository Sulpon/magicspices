# Волшебное дерево (Magic Spices) — дашборд и помощник

Сайт для склада и продаж: дашборд, помощник на ChatGPT, расчёт сводного по кварталу и свои страницы.
Данные хранятся на Netlify (Netlify Blobs) и общие для всех, кто знает пароль сайта.

## Что внутри

```
public/                 сайт (то, что видит браузер)
  index.html            страница с вкладками
  app.js                дашборд, помощник, страницы, настройки
  calc.js               расчёт сводного по кварталу
  core.js               чтение Excel, сопоставление названий, выгрузка
  dict.js               словарь подтверждённых названий
netlify/functions/api.mjs   сервер: хранилище, пароль, запросы к ChatGPT
netlify.toml            настройки Netlify
package.json            зависимость @netlify/blobs
```

## Развёртывание

Сайт с серверной частью нужно выкладывать через Git или через Netlify CLI.
Простое перетаскивание папки в Netlify (Netlify Drop) серверные функции не запускает, поэтому дашборд и помощник так работать не будут.

### Вариант 1. Через GitHub (рекомендую)

1. Создайте репозиторий на github.com (можно приватный) и загрузите в него **всё содержимое этой папки**, кроме `node_modules`, через кнопку «Add file → Upload files».
2. В Netlify откройте сайт **magicspicesltd** → *Site configuration* → *Build & deploy* → *Continuous deployment* → **Link repository** и выберите этот репозиторий.
   - Build command — оставьте пустым.
   - Publish directory — `public` (уже указано в `netlify.toml`).
3. Задайте переменные окружения (см. ниже) и нажмите *Deploys* → **Trigger deploy**.

После этого каждое изменение в репозитории будет само выкладываться на сайт.

### Вариант 2. Через Netlify CLI (с компьютера)

Нужен установленный Node.js 18+.

```bash
cd magicspices-dashboard
npm install
npx netlify-cli login
npx netlify-cli link        # выберите сайт magicspicesltd
npx netlify-cli deploy --prod
```

## Переменные окружения

Netlify → сайт → *Site configuration* → *Environment variables* → *Add a variable*:

| Переменная | Обязательно | Что это |
|---|---|---|
| `SITE_PASSWORD` | да | Пароль для входа на сайт. Без него любой, кто знает адрес, увидит цифры и сможет тратить ваш баланс OpenAI. |
| `OPENAI_API_KEY` | для чата | Ключ OpenAI: platform.openai.com → *API keys*. Без него чат выключен, подсказки на дашборде работают. |
| `OPENAI_MODEL` | нет | Модель для чата. По умолчанию `gpt-5-mini`. |

После изменения переменных сделайте новый деплой (*Deploys → Trigger deploy*).
В кабинете OpenAI поставьте месячный лимит расходов (*Settings → Limits*), чтобы не было сюрпризов.

## Первый запуск

1. Откройте сайт и введите пароль.
2. **Сводный → загрузите файлы квартала → «Сохранить в дашборд».** Так период сохранится вместе с суммами продаж (выручкой).
   Остаток на начало можно взять из файла прошлого сводного; если в дашборде уже есть предыдущий квартал, остатки возьмутся оттуда автоматически.
3. **Настройки → «Загрузить готовый сводный (.xlsx)»** — для старых кварталов, по которым остались только готовые сводные. Сохранятся количества, без сумм.
4. **Настройки → Валюта продаж** — например, ₸. **Запас для заказа** — на сколько месяцев вперёд считать «Что заказать» (по умолчанию 2).
5. **Страницы** — сюда можно загрузить свои .html-страницы, как раньше в «Расчётном кабинете».

## Как считаются подсказки

- **Минус** — остаток на конец периода меньше нуля.
- **Заканчивается** — остатка меньше чем на месяц продаж (продажи А + ВС за период ÷ число месяцев).
- **Что заказать** — сколько нужно, чтобы хватило на выбранное число месяцев; округляется вверх до размера упаковки из названия (например, «…30г/30» → кратно 30).
- **Продажи упали / выросли** — средние продажи в месяц изменились больше чем на 40% / 50% по сравнению с прошлым сохранённым периодом.
- **Без продаж** — на складе есть, а продаж за период не было.

Помощник (ChatGPT) получает сводку по всем сохранённым периодам и эти подсказки, а сами Excel-файлы на сервер не отправляются.
